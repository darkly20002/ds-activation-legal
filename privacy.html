سياسة الخصوصية - بوت Ds Activation

آخر تحديث: 15/08/2026

1. البيانات التي يجمعها البوت

  • معرفات Discord (مثل معرف المستخدم ومعرف السيرفر ومعرف القنوات) لتشغيل الوظائف داخل السيرفر.
  • سجلات الحضور والطابور إذا تم تفعيلها داخل السيرفر.

2. كيفية استخدام البيانات

تُستخدم البيانات لأغراض تشغيلية داخل السيرفر (تسجيل الحضور، إدارة الطابور، إرسال سجلات). لا نستخدم البيانات للإعلان أو بيعها لأطراف ثالثة.

3. تخزين البيانات

قد تُخزن بيانات بسيطة (مثل سجلات الحضور) في ملفات JSON محلية على خادم تشغيل البوت. احتفظ بنسخة احتياطية إن رغبت، ويمكنك طلب حذف بيانات سيرفرك عبر التواصل مع مالك البوت.

4. مشاركة البيانات

لا نشارك بيانات المستخدمين مع جهات خارجية إلا إذا طلب ذلك القانون أو طلبت منصة Discord ذلك حسب سياساتها.

5. حقوق المستخدم

يمكن لمالك السيرفر طلب حذف سجلات السيرفر أو بيانات معينة عن طريق التواصل مع مشغّل البوت.

6. الاتصال

للطلبات المتعلقة بالخصوصية أو لحذف البيانات، راسل مالك البوت أو قدّم طلبًا داخل قناة الدعم.
